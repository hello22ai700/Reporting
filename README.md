# ReportCraft AI - Smart Report Generator & Multi-Format Editor

Convert raw prompts and data into executive reports with interactive charts, live Word/Excel-style editing, and multi-format exports (**PDF**, **Word .docx**, **PowerPoint .pptx**, **Excel .xlsx**).

## 🌟 100% FREE Live Deployment (NO CREDIT CARD REQUIRED)

### Option 1: Direct GitHub Pages (Sabse Best & 100% Free Forever)
GitHub par hi direct host karein, koi bhi credit card ya external account nahi chahiye!

1. Code ko apne GitHub repository me push karein:
   ```bash
   git init
   git add .
   git commit -m "Deploy ReportCraft AI"
   git branch -M main
   git remote add origin https://github.com/<YOUR_USERNAME>/<YOUR_REPO>.git
   git push -u origin main
   ```
2. GitHub me repository ke **Settings** tab par jayein.
3. Left menu me **Pages** par click karein.
4. **Build and deployment** > **Source** me select karein: **GitHub Actions**.
5. Bas! Humne `.github/workflows/deploy.yml` pehle se setup kar diya hai. 1 minute me aapka live link activate ho jayega:
   `https://<YOUR_USERNAME>.github.io/<YOUR_REPO>/`

---

### Option 2: Vercel (1-Click, NO Card Required)
Vercel par free account me koi credit card nahi lagta:

1. [Vercel.com](https://vercel.com) par jayein aur **Continue with GitHub** karein.
2. **Add New... > Project** click karein aur apni GitHub repository select karein.
3. **Deploy** button daba dein.
4. 30 seconds me live public URL (`https://your-project.vercel.app`) ready ho jayega!
